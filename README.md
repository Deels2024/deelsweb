# Deels Web

Кликабельный веб-дизайн Deels в единой светлой фирменной системе. Проект содержит публичные страницы, карточки контента, личный кабинет и сценарии создания, а также адаптивную версию для компьютера и телефона.

## Что входит

- 26 основных экранов и состояний;
- челленджи, вертикальная лента, батлы, сторис и копилки;
- профиль, кошелёк, сообщения, уведомления, поиск и настройки;
- вход, регистрация и восстановление пароля;
- создание и редактирование челленджей, сторис и копилок;
- юридическая страница и полные реквизиты;
- адаптивные размеры 1440 px и 390 px;
- вертикальные карточки 9:16 и мобильный свайп.

## Структура стилей

- `app/styles.css` — общая сетка, компоненты и адаптив;
- `app/pages.css` — стили отдельных страниц и состояний;
- `app/themes/deels-main.css` — фирменная светлая тема Deels;
- `app/globals.css` — подключение базовых стилей.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

После запуска сайт доступен по адресу, указанному Vite в терминале.

## Проверка сборки

```bash
npm test
```

Команда собирает проект и запускает автоматическую проверку результата.

## Основные маршруты

Полная карта экранов доступна по маршруту `/screens`. Главные разделы: `/challenges`, `/feed`, `/battles`, `/stories`, `/campaigns`, `/profile`, `/wallet`, `/messages`, `/notifications`, `/search`, `/settings` и `/create`.
